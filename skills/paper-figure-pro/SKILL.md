# Paper Figure Pro — 交互式论文图表绘制

边聊边画。每一步展示给用户确认，不满意的立刻调整。
也可以直接给完整设计稿，一步到位。

## 交互模式 (默认)

```
1. 问类型 → 用户选 (架构图/数据图/热力图/...)
2. 问结构 → 几个分支? 哪些模块? 什么关系?
3. 给布局草图 → 文字描述 + 大致坐标, 用户确认
4. 给配色方案 → 2-3 色系预览, 用户选
5. 画图 → Visio COM 脚本逐模块出现
6. 问调整 → "哪里需要改?" → 循环直到满意
7. 保存 → .vsdx + .png + 时间戳备份
```

## 快速模式

用户说"直接画，不用问"时跳过交互，一步生成。

## 图类型

| 类型 | 工具 | 交互重点 |
|------|------|---------|
| 架构图/框架图 | Visio COM | 确认分支数、模块名、数据流方向 |
| 数据图 | matplotlib | 确认图表类型、数据、配色 |
| 热力图 | matplotlib | 确认数据矩阵、色阶 |
| 流程图 | Visio COM | 确认节点数和分支逻辑 |
| 消融柱状图 | matplotlib | 确认实验名和数值 |

## 配色

```
蓝:  bg=226,240,252  inner=190,220,248  mid=68,150,212  dark=26,95,160
橙:  bg=254,236,210  inner=250,216,166  mid=242,192,120  dark=200,78,10
灰:  input=235,235,240  output=215,220,228  op=150,165,175
```

每个容器一个色系，由浅入深：容器 → 内部盒 → 输出节点。

## 布局规则

1. **内容定宽** — 盒宽 = 文字需要，不拉伸填满容器
2. **对称** — 并行模块等宽等高同 y；日/周、低/高 必须镜像
3. **邻近** — 相关模块间距 0.2-0.3in
4. **层次** — 容器(最淡) → 内盒(中) → 输出(最深) → 终止符
5. **垂直居中** — 不等高的左右分支，短侧向长侧垂直居中靠拢

## 线条规则 (刚性)

**禁止多线聚集** — 这是最高优先级规则。

| 规则 | 做法 |
|------|------|
| 单点 ≤2 出线 | 3 线以上拆分 junction |
| 局部分流 | 并列模块间放 junction，同 y 水平展开 |
| 同源同向共用干线 | 一条竖线到局部分流点，再水平分出 |
| 进 junction 无箭头 | 干线到 junction 纯线条，出 junction 才加箭头 |
| 空间分离动作可见 | FFT→低/高用分叉线，视觉上看出"拆开" |

## 字体

- 主体 16pt, 强调 18pt, 输出 22pt, 运算符 30pt
- 容器标题 14pt
- 最小 ≥7pt (Jambor 2025)

## 设计禁忌

- 模块拉伸到容器全宽
- 文字太小留白太多
- 线条穿越模块表面
- 多余 4 色系
- 红绿配色
- 容器虚线边框
- 多线在一个点堆积

## 故障切换

```
Visio COM 可用? → Visio 画架构图
不可用? → matplotlib patches 画架构图
数据图: matplotlib 始终可用
```
